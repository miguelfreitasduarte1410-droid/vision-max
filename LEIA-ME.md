# Vision Max — site

Site estático responsivo desenvolvido a partir das imagens fornecidas para o projeto Vision Max.

## Arquivos

- `index.html`: página completa.
- `styles.css`: estilo, cores, versões mobile/tablet/desktop e animações sutis.
- `script.js`: menu responsivo, troca das vistas do protótipo, ampliação de imagens e animações de entrada.
- `assets/`: imagens da equipe e do protótipo, convertidas para WebP para carregamento leve, além da logomarca.

## Abrir

Abra `index.html` no navegador. A página funciona sem instalações e sem servidor. Para publicar, envie todo o conteúdo da pasta para um repositório GitHub e faça o deploy estático na Vercel (Framework Preset: Other, sem comando de build).

## Informações e limites

Os dados do projeto, os nomes da equipe, os papéis e as imagens do produto foram extraídos dos materiais fornecidos. Acesso automático ao perfil `@vision.max.empresa` no Instagram foi limitado, por isso **nenhuma informação específica de vídeos ou publicações foi inventada**. O botão do Instagram aponta para https://www.instagram.com/vision.max.empresa/.

As funcionalidades são apresentadas como **conceitos/propostas**, não como um produto já testado ou à venda. Os retratos foram exibidos sem ligação individual com os nomes, porque o material enviado não identificou explicitamente quem aparece em cada retrato. Para associar os retratos corretamente, basta confirmar a correspondência e ajustar o HTML.
